NOTES/TASK API — QUICK START

1. Install Node.js 18+ and MongoDB.
2. Open Terminal in the notes-task-api project folder.
3. Run: npm install
4. Run: cp .env.example .env
5. Ensure MongoDB is running and edit .env if your MongoDB URI differs.
6. Run: npm run dev
7. Test: http://localhost:5000/health
8. Import postman/Notes-Task-API.postman_collection.json in Postman.

See README.md for endpoint and query examples.
